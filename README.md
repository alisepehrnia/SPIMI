# SPIMI – Single-Pass In-Memory Indexing

A Python implementation of the **Single-Pass In-Memory Indexing (SPIMI)** algorithm, a classic external-memory indexing technique used in search engines and information retrieval systems to efficiently build large-scale inverted indexes.

## Highlights

- Implemented the **SPIMI algorithm** from scratch
- Built a complete **inverted index** for document collections
- Implemented **block-based indexing** and **block merging**
- Added **Boolean search** functionality for indexed documents
- Designed modular components for indexing, searching, and text preprocessing
- Processed large document collections without requiring the entire index to fit in memory
